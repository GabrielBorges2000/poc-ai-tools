# Poc ai tools

Este projeto é uma poc para testar os conceitos de tools usando modelos de ai.

## 🚀 Funcionalidades

- Layout responsivo e moderno

## 💻 Tecnologias

- [Node.js](https://nodejs.org/en)
- [Fastify](https://fastify.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Zod](https://zod.dev/)
- [AI SDK Vercel](https://ai-sdk.dev/)
- [Ollama](https://ollama.com/)

## Como Rodar o Projeto

1. Clone o repositório:
   ```bash
   git clone https://github.com/GabrielBorges2000/poc-ai-tools.git
   ```
   
2. Navegue até o diretório do projeto:
   ```bash
   cd poc-ai-tools
   ```
   
3. Instale as dependências:
   ```bash
   npm install
   ```
   
4. Configure as váriaveis de ambiente:
   ```bash
   PORT=3333 # => Optional
   DATABASE_URL='postgres://docker:docker@localhost:5432/database' # => Required
   ```
   
5. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
   
6. Abra o navegador e acesse:
   ```
   http://localhost:3333/api-docs
   ```
   
7. Envie um prompt no campo message para receber a resposta.
